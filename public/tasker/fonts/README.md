# Commissioner

Author: Kostas Bartsokas and the Commissioner Project Authors.
Source: https://github.com/kosbarts/Commissioner
License: SIL Open Font License 1.1; see OFL.txt.

Commissioner-Variable.woff2 is served locally. Supported axes: wght, slnt,
FLAR and VOLM. The project uses upright text, weights 400–650, and a mild
flare in headings. The font includes Russian and Kazakh Cyrillic.

No external font service or runtime package is required.
