# TASKER: исходный интерфейс

## Действующее решение пользователя, 23.09.2026

Сознательный откат пяти файлов public/index.html, public/styles.css, public/app.js, public/api.js и public/favicon.svg к 3600d55^ (66f58d7). Исходный макет с боковой навигацией, сеткой карточек и диалогом задачи — текущая визуальная база. Не улучшать композицию, цвета, тексты или структуру по собственной инициативе.

Направление «alem / бюро практики», Commissioner, световые окна и витрина public/tasker-system.html отменены как основа дальнейшего интерфейса. Их файлы сохранены для истории, но не являются текущим продуктом или шаблоном для новых экранов. Референсы Setka/ONY и прежнее решение о шрифте больше не определяют этот этап.

## Разрешённые отличия от снимка

- Имя TASKER в заголовке, метаданных, навигации, футере, описании и экране ошибки. Инициал T в знаке, загрузке и favicon. Ключи localStorage используют tasker:. HackAlem остаётся названием мероприятия.
- «Открываем пространство возможностей…» заменено на «Загружаем задачи…»; «СИЛЬНЕЕ ВМЕСТЕ» — на «СТУДЕНЧЕСКИЕ КОМАНДЫ». Остальные тексты сохранены по прямому указанию пользователя.
- Все заданные размеры шрифтов увеличены пропорционально в 8/7 раза: базовый текст 14 → 16 px, включая заголовки, подписи и адаптивные правила. Исходный стек Inter / системный sans-serif сохранён, новый шрифт не подключается.
- Боковая панель расширена с 226/204 до 260/248 px для более длинного имени и увеличенных подписей; соответствующий отступ рабочей области изменён вместе с ней. Иных изменений геометрии нет.
- В транспорте сохранён уже проверенный createTask для актуального POST /api/tasks. Контракт и сервер не откатываются вместе с оформлением.

## Данные и границы

Рейтинг и его расшифровка поступают с сервера, браузер их не пересчитывает. Исходный интерфейс позволяет читать каталог, фильтровать, сохранять избранное в браузере, просматривать команды и паспорт. Формы создания, AI, подтверждения, публикации и откликов в этом снимке отсутствуют: наличие серверного API не означает подключённый экран.

Язык последующих согласованных изменений — фактический. Список нежелательных оборотов: «пространство возможностей», «раскрой потенциал», «сильнее вместе». В текущем откате заменены только две явно указанные пользователем фразы; этот список не разрешает дополнительные изменения остальных текстов.
