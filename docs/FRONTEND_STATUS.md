Единственный основной запуск: npm start → http://127.0.0.1:3000/ **без preview**. Сервер и интерфейс работают из одной папки. Для проверки здесь использована отдельная DATA_FILE=/private/tmp/hackalem-tasker-review-20260923.json; рабочая база не затрагивалась.

Восстановленный app.js имеет каталог, фильтры, избранное, команды, демо-роли и паспорт. Он не содержит формы создания и не вызывает сохранённый createTask. AI-анализ, подтверждение, публикация, отправка/выбор откликов и этапы готовы в серверном API v1, но к исходному интерфейсу не подключены. Это сознательный результат запрошенного точного отката, а не заявление о готовом сквозном MVP.

Сервисы v2 и подставные Google-тесты не означают HTTP v2 и живой вход. Google-настройка по-прежнему отложена пользователем. Следующий функциональный этап выполняет второй Codex с учётом этого статуса.
