## Что работает

- Каталог из пяти синтетических задач, включая слабую задачу с рейтингом 20.
- Поиск, отраслевые фильтры, фильтр готовности, вид карточками и списком.
- Избранное в localStorage и отдельное представление сохранённых задач.
- Подробная карточка: все поля, расшифровка рейтинга, недостающие сведения и примеры поступивших идей.
- Объяснение формулы рейтинга и пользовательского сценария.
- Список пяти команд; демонстрационное переключение бизнес/команда и выбор команды.
- Прямые ссылки вида `/#task/task_coffee`, скопировать ссылку, закрытие карточки с клавиатуры.
- Пустая выдача, ошибка загрузки, повторная попытка, сохранение настроек после перезагрузки.
- Адаптация для узкого экрана.

## Граница первого этапа

Создание задачи, вопросы AI, редактирование, публикация и отправка отклика пока не реализованы в UI. Серверные данные подключены через GET API. Отправка решений бизнеса также относится к следующему этапу.

На этом этапе UI не вызывает никаких мутаций API. Отображение существующих откликов не является реализацией отправки отклика.

## Подключение для второго Codex

Раздавать `public/` с того же origin, что и API. `GET /api/state` возвращает task.rating, teams, proposals и meta по docs/API_CONTRACT.md. `GET /api/catalog` возвращает `{ tasks }` с фильтрами query/industry/level. MIME для `.js` должен быть text/javascript, для `.css` — text/css.

Без query-параметра preview UI загружает данные только через API. Ошибки не подменяются фикстурами. Рейтинг серверный: frontend не импортирует domain.mjs и не пересчитывает подтверждённые баллы. Запросы каталога отменяются при изменении фильтров.

Для отдельной оценки интерфейса открыт явный режим `?preview=1`, который читает `public/preview-data.json`. Этот файл — снимок уже существующего synthetic seed с рейтингами, рассчитанными domain.mjs при экспорте. Это не заменяет серверную реализацию.

## Запуск предпросмотра

```sh
npm run preview
```

Открыть http://127.0.0.1:4173/?preview=1.

Если package.json у второго участника отличается, добавить только строку `"preview": "node scripts/preview.mjs"` в scripts, не заменять весь файл. Сервер preview только раздаёт статические файлы; продуктовый server.mjs принадлежит второму участнику.
