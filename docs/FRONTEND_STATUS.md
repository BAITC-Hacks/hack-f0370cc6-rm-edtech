- Источники, принципы, ограничения и сценарий защиты: docs/BRAND_DIRECTION.md.

## Форма и данные

«Предложить задачу» открывает демонстрационную роль бизнеса. Ввод: raw до 4000 символов, industry из meta.industries. Отправляются только role=business, businessId=business_demo, raw, industry. Во время запроса поля и повторная отправка блокируются.

Успех показывается только после проверенного ответа 201. Черновик можно увидеть снова в разделе «Ваши черновики» на экране создания. Исходный текст без подтверждённых условий не получает баллы. Потеря сети/некорректное подтверждение не считаются успешной записью и не вызывают автоматический повтор POST.

Обычный запуск: npm start, http://127.0.0.1:3000/. Статический просмотр: npm run preview, http://127.0.0.1:4173/?preview=1. Preview явно обозначен и не подменяет неработающий API. В демо-среде примеры синтетические, роли не являются аутентификацией.

## Граница готовности

AI-вопросы, полноценное редактирование полей, ручное подтверждение, публикация, отправка откликов и решения бизнеса в интерфейс ещё не подключены. Просмотр seed-откликов не является реализацией отправки отклика. Полный сквозной MVP ещё не завершён.

Браузерные записи проверялись через отдельный DATA_FILE в /private/tmp; рабочая демонстрационная база тестами не изменялась. Серверные тесты также используют временные базы.
