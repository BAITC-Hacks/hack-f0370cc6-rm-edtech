# Просмотр интерфейса первого этапа

Требуется Node.js 20+. Сторонние пакеты не нужны.

```sh
npm run preview
```

Адрес: http://127.0.0.1:4173/?preview=1.

Проверка транспорта:

```sh
npm test
```

Сервер второго участника уже интегрирован. Для обычной работы используйте `npm start` и http://127.0.0.1:3000/ без `?preview=1`. Команда preview остаётся отдельным способом посмотреть статическую фикстуру.

В архив первого этапа входят public/, scripts/preview.mjs, tests/e2e/catalog-api.test.mjs и документы интерфейса. При переносе сначала проверьте существующие файлы репозитория. Корневой package.json не включён, чтобы не перезаписать изменения второго участника. Для команды предпросмотра добавьте в scripts:

```json
"preview": "node scripts/preview.mjs"
```

Весь каталог и его отображение находятся в public/app.js и public/styles.css. public/api.js отвечает только за получение данных по общему контракту. public/preview-data.json используется только в явно выбранном режиме предпросмотра.
