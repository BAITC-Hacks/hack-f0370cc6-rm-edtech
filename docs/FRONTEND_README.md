# Интерфейс TASKER

## Единая рабочая сборка

Официальный репозиторий: https://github.com/BAITC-Hacks/hack-f0370cc6-rm-edtech. В feat/frontend объединены backend до 725948c и исходный интерфейс 66f58d7 с согласованными изменениями TASKER и размера текста. Отдельный корневой проект не создавался. После сохранения своей работы второй участник получает и объединяет опубликованную ветку по docs/COORDINATION.md.

Node.js 20+, без сторонних пакетов:

```sh
npm start
```

Основной адрес: http://127.0.0.1:3000/ без preview. Этот же процесс раздаёт интерфейс и API. Порт на другом компьютере может отличаться через PORT; это не другой проект.

```sh
npm test
```

135 проверок: сервер v1, AI и fallback, сервисы v2, хранение, HTTP и транспорт интерфейса. Для тестов используются отдельные временные базы.

## Текущий интерфейс

Восстановлены боковая навигация, каталог карточками/списком, поиск, фильтры, избранное, команды, выбор демонстрационной роли и паспорт задачи из 3600d55^. Рейтинг и баллы команд приходят с сервера. Шрифты увеличены в 8/7 раза; база 16 px. Палитра и остальные тексты/структура исходного снимка сохранены, кроме бренда и двух явно согласованных фраз.

Исходный app.js использует GET /api/state и GET /api/catalog. Обе схемы совместимы с текущим API v1. В api.js сохранён createTask с обработкой неопределённого результата без автоматического повтора POST; исходный экран не вызывает его. Формы создания, AI, подтверждения, публикации и откликов отсутствуют в восстановленной версии. Их последующее подключение ведёт владелец функционала; серверные реализации при откате сохранены.

API v2 пока существует как внутренние сервисы и предложение контракта, без HTTP и трёх новых экранов. Живой Google-вход отдельно отложен пользователем.

## Предпросмотр и архив

Для статического просмотра тех же файлов можно выполнить npm run preview и открыть http://127.0.0.1:4173/?preview=1. Это явно обозначенная фикстура без серверных записей, не адрес совместной проверки frontend/backend. Ошибка API не подменяется preview автоматически.

Временный снимок на 4174 служил только сравнению с первой версией. Он не является рабочей сборкой. public/tasker-system.html и public/tasker/** — сохранённая прежняя витрина Commissioner; пользователь отменил это визуальное направление. Не переносить её в рабочие экраны.

Актуальные визуальные ограничения: docs/BRAND_DIRECTION.md. Результат проверок и занятые файлы: docs/FRONTEND_STATUS.md. Правила интеграции: docs/COORDINATION.md.
