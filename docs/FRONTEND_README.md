# Интерфейс TASKER

## Витрина новой системы

После `npm start` открыть http://127.0.0.1:3000/tasker-system.html. Это отдельная витрина утверждённого направления: Commissioner, строгая сетка и подсветка подтверждённых условий, без иллюстраций. Основной интерфейс на `/` пока сохраняет прежнее оформление. Повторное согласование трёх визуальных решений не требуется; перенос в основной интерфейс остаётся отдельным небольшим этапом.

Токены: `public/tasker/tokens.css`. Витрина: `public/tasker-system.html`, `public/tasker/system.css`, `public/tasker/system.js`. Знак: `public/tasker/mark.svg`. Все девять цветов исходной версии сохранены буквально. Commissioner загружается из `public/tasker/fonts/Commissioner-Variable.woff2`; рядом лицензия OFL. Системная подстановка Verdana / sans-serif. Внешние шрифтовые сервисы и зависимости не нужны.

По умолчанию показан Jol Logistics с серверным рейтингом 45: пробел в данных остаётся между подтверждёнными условиями. Семь подписанных окон показывают группы рейтинга, каждая часть — конкретное поле. Нажатие переводит фокус в соответствующий раздел раскрытого паспорта. Диалог использует ту же расшифровку. Общий балл и баллы групп не пересчитываются на клиенте.

Поиск, отрасль и готовность фильтруют загруженные опубликованные примеры; селектор позволяет сравнить задачи на 20/45/65/90/100 баллов. Пустая выдача очищает паспорт, блокирует диалог и предлагает сброс. Переключатель 14/15/16 px меняет Commissioner в образцах управления; ввод остаётся 16 px. Навигация и кнопки сохранения только демонстрируют состояния: записей в API и localStorage нет.

По умолчанию задача читается через существующий GET /api/catalog. Для полностью статического просмотра: http://127.0.0.1:4173/tasker-system.html?preview=1 после `npm run preview`. Только явный preview использует существующую фикстуру. Ошибки API показываются без подмены данных.

## Основное приложение

Node.js 20+, без сторонних пакетов.

```sh
npm start
```

Открыть http://127.0.0.1:3000/ без preview. Каталог и создание черновиков используют настоящий локальный API.

```sh
npm test
```

32 проверки общей сборки, включая транспорт создания черновика и отказ от автоматического повтора записи при неопределённом результате сети.

Для отдельного просмотра оформления:

```sh
npm run preview
```

Адрес http://127.0.0.1:4173/?preview=1. В этом режиме каталог использует синтетическую фикстуру, а сохранение отключено. Ошибка настоящего API не переключает интерфейс в preview автоматически.

Работают каталог, поиск и фильтры, паспорт задачи, избранное, команды, демонстрационные роли, создание исходного черновика и повторное чтение сохранённого описания. AI-вопросы, подтверждение, публикация и отклики — последующие этапы.

Визуальный язык и обоснование: docs/BRAND_DIRECTION.md. Текущий статус и интеграция: docs/FRONTEND_STATUS.md. Совместная работа: docs/COORDINATION.md. Архивы для обмена больше не нужны.
